# AQA Psychology Social Influence Flashcards

A mobile-first revision deck for AQA Psychology.

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload `index.html` into the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.

Your site will then publish from GitHub Pages.

## Notes

- This version is designed mainly for phones.
- The study guidance is in its own collapsible section above the cards.
- The file is ready to expand later with more topic groups.
- Keep the main file name as `index.html`.

## Adding more topics later

Add new flashcards to the `ALL_CARDS` array in `index.html`, and add any new topic names to the topic dropdown.
